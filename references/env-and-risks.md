## 一、运行环境与已知坑

**Windows + Python 3.11**（代码兼容 3.11 及以上）。下面每一条都是踩过的坑，照做即可。

| 坑 | 大白话 | 怎么处理 |
|---|---|---|
| CSV 编码 | 直接写 UTF-8，Excel 打开中文会乱码 | CSV **必须 `utf-8-sig`**；JSONL 用 `utf-8` + `ensure_ascii=False` |
| 文件被占用 | `os.replace` 时文件正被 Excel / 预览面板打开，报 `WinError 32` | **明确报错，不静默覆盖、不删用户文件、保留 `.tmp`**；提示先关掉占用再重试 |
| 控制台乱码 | Windows 控制台默认 GBK，中文输出成乱码 | `sys.stdout.reconfigure(encoding='utf-8')` |
| 路径分隔符 | 反斜杠在字符串里容易出岔子 | 一律 `pathlib.Path` + **正斜杠** |
| 中文分词 | 中文不像英文有空格，硬装分词包容易翻车 | 默认**字符 n-gram（`char_wb` 2–4）零依赖**；`jieba` 仅可选 |
| sklearn 版本 | 老版本不支持 3.11 | 用 `scikit-learn>=1.4`（1.4+ 才正式支持 3.11） |
| numba / llvmlite | 缺 VC++ 运行库，装不上 | 靠「明确不装」绕开，不进依赖 |
| xlsx 只读锁 | 被预览面板 / Excel 打开过的 xlsx 可能带只读锁，之后改不动 | **先关掉占用程序，或另存新名再改** |
| 没有 git | 工作区**无 git 仓库**，回滚没版本可用 | 靠 **sha256 指纹 + snapshots** 留痕；**实施前先备份工作区** |

> `sha256 指纹` 大白话：给文件算一串固定长度的「指纹」，跑前跑后一对，就知道有没有被动过。`原子写` 见 `redlines.md` 第 5 条。

## 二、依赖清单与许可证

**许可证白名单：MIT / Apache-2.0 / BSD-3-Clause**；**LGPL / AGPL / GPL 不进运行时**。

| 类别 | 包 | 说明 |
|---|---|---|
| **必需** | `requests` / `PyYAML` / `pandas` / `scikit-learn>=1.4` / `openpyxl` | 请求、读配置、整理数据、聚类、导出 Excel |
| **可选** | `model2vec` / `jieba` | 装了自动增强，不装照跑 |
| **明确不装** | 重型深度学习框架 / 需要本地编译的聚类组件 / 强制数据库或容器的研究工具 / 渠道专用非官方抓取器 | 太重、Windows 编译坑、需 key、或平台条款风险 |
| **不申请** | 任何外部 API key | 脚本不调外部 API，主题命名交会话自带 LLM |

“明确不装”项的共同原因是 Python 版本冲突、强制数据库或容器、需要外部密钥，或在 Windows 上存在编译风险。这里只吸收公开方法与规范，不部署其服务；方法清单见 `analysis-playbook.md` 第一节。

## 三、离线闭环零第三方依赖

目标是：**在一台干净的 Python 3.11+ 上，不装任何包，也能一键试跑通 MVP。**

- [ ] **聚类有标准库兜底**：装了 `scikit-learn` 自动增强，没装也能用内置实现跑出结果。
- [ ] **Excel 出口可选**：没有 `openpyxl` 就跳过 xlsx，其余出口照常。
- [ ] **离线模式不读 yaml**：`--offline --fixtures` 直接吃示例数据，不依赖配置文件解析。
- [ ] 首次联网只开 {{CHANNEL_A}} 一个渠道验证，别一上来全开（见第四节风险 5）。

## 五、明确做不到清单
